# Cloud Chat

A real-time, multi-room chat application built with Python, FastAPI, and WebSockets, featuring secure phone number authentication via Google Firebase. 

## Features

- **Real-Time Messaging**: Lightning-fast, two-way communication using WebSockets.
- **Chat Rooms**: Isolated, channel-based chat rooms for private group conversations.
- **Secure Authentication**: OTP (One-Time Password) SMS login using Firebase Phone Auth.
- **Modern UI**: A responsive, Discord-inspired dark theme single-page application (SPA).
- **Cloud Ready**: Configured for seamless deployment on Render with automatic HTTPS and WSS (WebSocket Secure) routing.

## Tech Stack

- **Backend**: Python, FastAPI, Uvicorn
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Authentication**: Google Firebase (Phone Auth)
- **Deployment**: Render

## Local Setup

### Prerequisites
- Python 3.8 or higher
- A Google Firebase Project with Phone Authentication enabled
